MY WEBSITE: SIMPLE PROJECT MAP
================================

WHAT THIS PROJECT IS
--------------------
This is Akash Nagapure's personal portfolio. Astro turns files in src/pages
into web pages. Public files are copied directly to the website.

START HERE
----------
src/pages/index.astro       Main portfolio home page: /
src/pages/404.astro         Automatic page-not-found screen
src/styles/global.css       Shared site CSS
astro.config.mjs            Astro settings and website address

PAGE CONNECTIONS
----------------
Projects.astro -> Blogs/Autopatchblog.astro
courses.astro -> the four future blog pages listed above
Every blog article -> blogslayout.astro
The original portfolio pages keep their complete page-specific markup and
scripts, so their visual design and interactive behavior remain unchanged.

DATA AND IMAGES
---------------

public/robots.txt                    Search crawler rules
public/sitemap.xml                   URLs for Google Search Console import

URL RULE
--------
Old HTML names are now Astro source files, but the built website keeps the
same .html URLs. This protects existing bookmarks and search-engine links.

COMMON COMMANDS
---------------
npm install                         Install packages
npm run dev                         Start local development server
npm run build                       Check and build the website
npm run preview                     Preview the production build

AUTOSAVE
--------
.vscode/settings.json saves edited files after one second automatically.
